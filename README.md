Practical 7 — Automated testing with GitHub Actions
Step 1 — Create project:
bashmkdir testdemo
cd testdemo
git init
Step 2 — Create test_sample.py:
bashcat > test_sample.py << 'EOF'
def add(a, b):
    return a + b

def test_add():
    assert add(2, 3) == 5
    assert add(0, 0) == 0
    assert add(-1, 1) == 0

def test_string():
    assert "hello".upper() == "HELLO"
EOF
Step 3 — Create workflow:
bashmkdir -p .github/workflows
cat > .github/workflows/test.yml << 'EOF'
name: Automated Testing

on:
  push:
    branches:
      - main

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v3

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.x'

      - name: Install pytest
        run: pip install pytest

      - name: Run tests
        run: pytest test_sample.py -v
EOF
Step 4 — Push:
bashgit remote add origin https://github.com/yourusername/testdemo.git
git branch -M main
git add .
git commit -m "Add test file and testing workflow"
git push -u origin main
Show the Actions tab — you'll see each test passing with green checkmarks.

Practical 8 — Docker basics (Dockerfile)
Step 1 — Create project:
bashmkdir dockerdemo
cd dockerdemo
Step 2 — Create app.py:
bashcat > app.py << 'EOF'
from flask import Flask
app = Flask(__name__)

@app.route('/')
def home():
    return "<h1>Hello from Docker!</h1>"

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
EOF
Step 3 — Create requirements.txt:
bashecho "flask" > requirements.txt
Step 4 — Create Dockerfile:
bashcat > Dockerfile << 'EOF'
FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]
EOF
Step 5 — Build and run:
bashdocker build -t myflaskapp .
docker images
docker run -d -p 5000:5000 myflaskapp
docker ps
Open browser → http://localhost:5000 → show "Hello from Docker!"
bashdocker stop $(docker ps -q)

Practical 10 — Ansible playbook (install Nginx)
Step 1 — Install Ansible (if not installed):
bashsudo apt update
sudo apt install ansible -y
ansible --version
Step 2 — Create inventory file:
bashcat > inventory.ini << 'EOF'
[webservers]
localhost ansible_connection=local
EOF
Step 3 — Create playbook install_nginx.yml:
bashcat > install_nginx.yml << 'EOF'
---
- name: Install and start Nginx web server
  hosts: webservers
  become: yes

  tasks:
    - name: Update apt cache
      apt:
        update_cache: yes

    - name: Install Nginx
      apt:
        name: nginx
        state: present

    - name: Start Nginx service
      service:
        name: nginx
        state: started
        enabled: yes

    - name: Verify Nginx is running
      command: systemctl status nginx
      register: nginx_status

    - name: Print status
      debug:
        msg: "Nginx is running successfully!"
EOF
Step 4 — Run the playbook:
bashansible-playbook -i inventory.ini install_nginx.yml
Step 5 — Verify:
bashsystemctl status nginx
curl http://localhost
Browser → http://localhost → Nginx welcome page.
Step 6 — Show idempotency (run again — nothing changes):
bashansible-playbook -i inventory.ini install_nginx.yml
# All tasks show "ok" not "changed" — this is idempotency
